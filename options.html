Como usar o Ollama local:
1. Instale o Ollama no Windows
2. No terminal: ollama pull qwen3:8b
3. Mantenha o Ollama em execução (porta 11434)
4. Se o teste retornar 403, defina a variável de ambiente OLLAMA_ORIGINS=chrome-extension://* e reinicie o Ollama
Endpoint OpenAI-compatible do Ollama. O padrão é http://127.0.0.1:11434/v1
Qwen3 8B é texto (sem visão). O alt text usa o contexto da página (figcaption, texto adjacente, nome do arquivo).
Como obter uma chave de API:
1. Acesse openrouter.ai
2. Crie uma conta ou faça login
3. Vá para a seção de chaves de API
4. Crie uma nova chave e copie-a
5. Cole a chave abaixo
Sua chave de API é armazenada localmente no seu navegador e nunca é enviada para servidores de terceiros.
Modelos baratos e suficientes para JSON de remediação. Gemini 2.5 Flash Lite e GPT-5 Nano aceitam visão para alt text.

⚡ Comportamento

Se ativado, o plugin analisará e aplicará automaticamente melhorias de acessibilidade sempre que uma nova página for carregada na aba ativa.
Exibe notificações quando a análise de acessibilidade é concluída.

ℹ️ Sobre

Accessify v1.1.0

Um plugin do Chrome que transforma páginas web em acessíveis seguindo as diretrizes WCAG 2.1, com foco em usuários cegos ou de baixa visão.

Recursos:
  • Análise automática de conformidade WCAG
  • Geração de textos alternativos com IA
  • Otimização de estrutura HTML
  • Melhorias de contraste de cores
  • Adição de ARIA labels
Aviso Legal:
Este plugin é fornecido "como está". Sempre revise as mudanças de acessibilidade antes de aplicá-las em produção. Recomenda-se testar com usuários reais e ferramentas de acessibilidade profissionais.

Recursos úteis:
• Diretrizes WCAG 2.1
• Ollama
• OpenRouter
• Web Accessibility Initiative (WAI)
